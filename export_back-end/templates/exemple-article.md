# Guide Complet pour Créer un Article

Ceci est un **exemple d'article** au format Markdown. Vous pouvez le copier et l'adapter pour créer vos propres contenus.

## Structure d'un Article

### Frontmatter (Métadonnées)

Le frontmatter en haut du fichier contient les métadonnées de l'article :

- `title` : Titre principal (utilisé comme H1)
- `category` : Catégorie de l'article (doit correspondre aux options de votre CMS)
- `type` : Type d'article (Guide, Actualité, etc.)
- `image` : Chemin vers l'image de couverture
- `readTime` : Temps de lecture estimé
- `excerpt` : Résumé court pour SEO et listes
- `publishedAt` : Date de publication (format: "JJ Mois AAAA")
- `featured` : Afficher sur la page principale du blog (true/false)

## Conseils pour Vos Articles

1. **Optimisez pour le SEO** :
   - Utilisez des mots-clés pertinents dans le titre
   - Écrivez un excerpt de 150-200 caractères
   - Structurez avec des titres H2 et H3

2. **Rendez le contenu scannable** :
   - Utilisez des listes
   - Mettez en gras les points importants
   - Ajoutez des images pour aérer

3. **Longueur idéale** :
   - Minimum 500 mots pour un bon SEO
   - Optimal : 1000-1500 mots

4. **Images** :
   - Image de couverture : min 1200x630px
   - Images dans l'article : optimisées avec Cloudinary
